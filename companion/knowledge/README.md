# Conocimiento del servidor

Todo archivo `.md`, `.txt` o `.json` de esta carpeta se añade a las instrucciones de la IA en cada pregunta.
Los archivos que empiezan con `_` y este README se ignoran.

Sirve para que la IA no invente datos que dependen de WoW Forever. Por ejemplo:

- `mazmorras.md`: nombre de cada mazmorra, zona, entrada (x, y) y rango de nivel recomendado.
- `zonas.md`: zonas de misiones por rango de nivel y facción.
- `notas.md`: cambios propios de Forever que el modelo no puede conocer.

Mira `_ejemplo-mazmorras.md`. Para activarlo, cópialo sin el `_` inicial y corrige los datos con información verificada del juego.
